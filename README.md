# DocSweep

Automation tool for checking drawings and manuals across Vertiv repositories.

# Setup

Paste the two folders (chromedriver-win64, chrome-win64) to "C:\\Program Files\\Google," and you can now run the .exe file.

# How to Use

1. Once you open the .exe file, it automatically opens the Chrome browser (for testing) and the four repository sites.
2. Follow the setup for each site below:

   a. **Vertiv:**
	> There is a pop-up message saying "The page you're viewing is for English (United States) region." Click "Proceed."

   b. **Asset Library:**
	> Click "Login."
	> Close the pop-up message regarding the new feature by clicking "Don't Show Again."

   c. **PD Cloud:**
	> Click the search icon in the right-side pane (not the one in the top navigation bar), and select "Advanced."

   d. **MASW:**
	> Ensure you are successfully logged in.

3. Click "Verify Sites." It should show "Ready" for all four sites.
4. Click "Browse" and select the Excel file generated by the VEGA agent.
5. Click "Start Sweep."
